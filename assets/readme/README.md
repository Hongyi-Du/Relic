# README illustrations

- `relic-overview.svg` is a compact, editable schematic of the paper's
  interface-review example: recurring failure → governed protocol → the same
  requirement with a new reviewer. It illustrates the method, not a measured
  trajectory or an experimental result.
- `mechanism-main.png` is the current full mechanism illustration copied from
  the Relic project site's `public/paper/figures/mechanism-main.png`. It retains
  the paper's original labels, colors, and content at 3188 × 1913 pixels.

The underlying research is [Relic: From Multi-Agent Collaboration to Persistent
Organizational Capability](https://arxiv.org/abs/2609.32965). The interactive
version is available on the [project website](https://hongyidu.ai/relic/en).

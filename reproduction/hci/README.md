# HCI reproduction boundary

The HCI implementation is deliberately isolated on the `hci` branch, where
`docs/HCI_GUIDE.md` provides its startup and replay instructions. `main` keeps
only this navigation document so the canonical paper-reproduction core does not
duplicate HCI source code.

The release does not include author-selected, sanitized HCI paper traces,
participant materials, questionnaires, or historical participant data. Those
assets must be supplied and reviewed by the authors before a historical HCI
case can be claimed or replayed as paper evidence.

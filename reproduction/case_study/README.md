# Selected case-study boundary

This location is reserved for a small author-reviewed set of sanitized
`relic-trace-v1` cases and their provenance metadata. The public Inspector can
validate and replay such a trace once supplied, but this release does not
invent a case from aggregate values, checkpoint counts, or mock output.

For each future selected case, publish the paper section/figure reference,
source run or cell identity, code/config binding, exporter/redaction version,
reviewer, selection rationale, and final trace hash alongside the trace.
